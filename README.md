# CWE
MATLAB toolbox to execute a Common Waveform Estimation (CWE) method developed by Takeda et al. (2010).

Please read readme.pdf for more detailed information.

## Reference
Takeda Y., Sato M., Yamanaka K., Nozaki D., Yamamoto Y., A generalized method to estimate waveforms common across trials from EEGs. NeuroImage (2010); 51(2):629-41.
